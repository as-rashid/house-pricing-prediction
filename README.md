# House Pricing Prediction

This project uses a house pricing dataset and multiple linear regression algorithms to build a price prediction model.

## Dataset

File: `house_pricing_dataset.csv`

Columns:

- `price` (target)
- `area`
- `bedrooms`
- `bathrooms`
- `stories`
- `mainroad`
- `guestroom`
- `basement`
- `hotwaterheating`
- `airconditioning`
- `parking`
- `prefarea`
- `furnishingstatus`

## Notes

- Use `main.ipynb` as the working notebook.
- Keep the workflow simple and focused on multiple linear regression.
